## Module System

```rust
// src/lib.rs
mod garden;          // declare module, maps to src/garden.rs
mod kitchen {        // inline module
    pub fn cook() { println!("cooking!"); }
}

pub use garden::Vegetable; // re-export to simplify external paths
```

```rust
// src/garden.rs
pub struct Vegetable {
    pub name: String,
    calories: u32, // private field
}

impl Vegetable {
    pub fn new(name: &str) -> Vegetable {
        Vegetable { name: name.to_string(), calories: 0 }
    }
}

pub mod seasonal; // nested submodule, maps to src/garden/seasonal.rs
```

<Callout type="insight">
Rust visibility is **private** by default; `pub` explicitly makes things public. This is the opposite of JS (where exporting requires `export`), but it's safer: API boundaries are crystal clear, and internal implementation details are never accidentally exposed.
</Callout>

## Cargo.toml: Dependency Management

```toml
[package]
name = "my-app"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = { version = "1", features = ["derive"] }
tokio = { version = "1", features = ["full"] }
reqwest = "0.11"

[dev-dependencies]   # test-only dependencies
criterion = "0.5"

[features]           # optional features
default = []
postgres = ["sqlx/postgres"]
```

<Callout type="tip">
The `features` system is a core design of the Rust ecosystem — crates only compile the necessary code by default, and users opt into features as needed. This keeps binaries smaller and builds faster. Think of it as tree-shaking, but at compile time.
</Callout>

## Cargo Workspace: Monorepo

```toml
# workspace/Cargo.toml (root)
[workspace]
members = [
    "crates/core",
    "crates/web",
    "crates/cli",
]
resolver = "2"
```

```
workspace/
├── Cargo.toml          # workspace root
├── Cargo.lock          # shared lock file
└── crates/
    ├── core/           # shared logic library
    │   ├── Cargo.toml
    │   └── src/lib.rs
    ├── web/            # Axum web service
    │   ├── Cargo.toml  # depends on core
    │   └── src/main.rs
    └── cli/            # CLI tool
        ├── Cargo.toml  # depends on core
        └── src/main.rs
```

```toml
# crates/web/Cargo.toml
[dependencies]
core = { path = "../core" }  # local dependency
```

## Publishing to Crates.io

```bash
# log in (requires a crates.io account)
cargo login <token>

# pre-publish checks
cargo check
cargo test
cargo doc --open   # preview documentation

# publish
cargo publish
```

```rust
// doc comments automatically generate docs.rs pages
/// Converts Celsius to Fahrenheit.
///
/// # Examples
/// ```
/// use my_crate::celsius_to_fahrenheit;
/// assert_eq!(celsius_to_fahrenheit(0.0), 32.0);
/// ```
pub fn celsius_to_fahrenheit(c: f64) -> f64 {
    c * 9.0 / 5.0 + 32.0
}
```

<Callout type="note">
The `# Examples` code blocks inside `///` doc comments are automatically run by `cargo test` — documentation is also tested, so docs are always up to date.
</Callout>
